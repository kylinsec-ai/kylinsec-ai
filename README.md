## About

I research offensive security and build tools that make security concepts observable, testable, and reproducible.

我关注进攻性安全研究与安全工具工程化，尝试把对攻击技术的理解转化为可验证、可复现的工程实践。

- **Research** — adversary emulation, malware analysis, and implementation-level security research.
- **Engineering** — security tooling and systems programming with Go and Rust.
- **Defense** — translating offensive techniques into better detection, validation, and security understanding.

## Principles

- **Evidence over assumptions.** Separate verified behavior from hypotheses.
- **Reproducibility over spectacle.** Prefer clear methods, tests, and documented limitations.
- **Research with boundaries.** Work in authorized labs and assessments; respect responsible disclosure.
